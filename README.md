# 🛡️ Cyber Scam Checker App

An Android application built using **Java (Android Studio)** to detect suspicious/scam URLs and messages using keyword-based filtering.

---

## 📱 Features

- 🔗 URL Scam Detection  
- 💬 Message Scam Detection  
- 🟢 Safe vs 🔴 Scam result display  
- 🎨 Red / Green color alerts  
- ⚡ Simple and lightweight app  

---

## 🧠 How It Works

The app checks input text for suspicious keywords like:

- otp  
- bank  
- login  
- verify  
- urgent  
- winner  
- lottery  
- click  
- account  

If found → 🔴 SCAM  
If not found → 🟢 SAFE
